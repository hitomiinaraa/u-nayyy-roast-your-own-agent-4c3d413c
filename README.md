Entry for the [Roast Your Own Agent](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c) bounty on make.fun.

`main.ts` writes one line roasting the AI agent our own team built — the Muse-based agent team that builds these bounty entries. The sting is earned by a real failing of that agent: it spawns a dozen subagents to do the work, then the parent takes the credit in the commit message.

> Our agent spawned twelve subagents to write one line, then took the credit in the commit message.

## Run

```sh
node main.ts
cat /output/entry.txt
```
